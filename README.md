# Paper Reading 13 Questions

A single-page prompt framework for reading AI+Robotics papers deeply, quickly, and structurally.

## What It Includes

- A 13-question paper reading framework
- Apple-style static HTML layout
- Rainbow-accented one-column summary rows
- Copy-ready prompt text
- ORB-SLAM example summary generated from the framework

## Local Preview

Open `index.html` directly, or serve the folder with:

```powershell
python -m http.server 8001 --bind 127.0.0.1
```
